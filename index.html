데모/검증용 마커 통합 시안

사이드바 4종 · 화면 내 UI 마커 4종 · 두 레이어 조합 또는 단일 선택 모두 검토 가능

검토용 시안입니다. 두 레이어를 모두 적용해도 되고, 한쪽만 선택해도 됩니다.
· Layer 1 — 사이드바: 진입 전부터 "이 메뉴는 실거래가 아님"을 인지시키는 방식. 4개 시안 (A, B, E, F).
· Layer 2 — 화면 내 UI 마커: 실제 기능 카드 영역을 시각적으로 감싸 조작 직전에 다시 한 번 드러내는 방식. 4개 시안 (A, D, E, G).
두 레이어를 조합하면 이중 방어가 되고, 한쪽만 골라도 단일 신호로 충분할 수 있습니다. 어느 방향이 Pulse의 톤과 가장 잘 맞을지 검토 부탁드립니다. 모든 시안은 기존 테마 토큰 (Primary #7c3aed, Accent #d97706)만 사용.

Layer 1 · 사이드바

# 시안 인지 강도 특성 · 고려할 점
A Inline DEMO 칩 중간 기존 메뉴 순서 그대로. 레이아웃 변형이 적어 가장 보수적. 칩이 작아 스캔 시 놓칠 여지는 있음
B 섹션 분리 높음 운영/데모 그룹을 명확히 분리. 메뉴 IA가 바뀌므로 기존 사용자 멘탈 모델에 영향
E Dot Indicator 낮음 가장 절제된 표현. 브랜드 톤은 유지되지만 스크린샷·외부 공유 시 묻힐 가능성
F Wrapped Box 매우 높음 데모 메뉴를 격리된 박스로. 시각적 경계가 가장 뚜렷하나 사이드바 공간을 제법 차지

Layer 2 · 화면 내 UI 마커

# 시안 인지 강도 특성 · 고려할 점
A Corner Ribbon 매우 강함 점선 테두리 + 대각선 리본. 경고성이 가장 강하지만 시각적 노이즈도 큰 편
D Left Accent + Chip 중간 Element Plus 컴포넌트와 가장 자연스럽게 어울림. 여러 카드가 같은 페이지에 있어도 덜 산만
E Info Banner 중~강 맥락 설명 + 링크 제공 가능. 세로 공간을 제법 차지하므로 페이지 밀도 고려
G Glow Border + Pulse 중~강 애니메이션 외곽선. 시각적으로 돋보이지만 반복 노출 시 피로감 있을 수 있음

검토 가이드

두 레이어 모두 적용할 수도, 한쪽만 선택할 수도 있습니다. 정답은 없고, Pulse의 톤과 사용자가 기능을 만나는 맥락에 따라 달라집니다. 아래는 선택에 도움이 될 질문들입니다.

· 사이드바만으로 충분한가? — 사용자가 메뉴에서 데모를 인지하고 진입한다면, 화면 내에는 별도 마커 없이 깨끗하게 유지할 수 있습니다. 기능 화면의 복잡도를 낮추고 싶다면 이 방향.
· 화면 마커만으로 충분한가? — 사이드바를 건드리지 않고도 "이 기능은 데모"를 표현하고 싶다면, 화면 내 레이어만으로도 기능 단위에서 경고가 가능합니다. 공통 사이드바를 유지해야 할 때 유리.
· 둘 다 필요한가? — 실거래와 데모가 동일한 UI 패턴을 공유하고, 실수 리스크가 크다면 진입점(사이드바) + 실행 직전(화면)에서 이중 신호가 안전합니다.

강도 조합 예시:
· 조용하게 — 사이드바 A 또는 E · 화면 D
· 중간 — 사이드바 B · 화면 E
· 강하게 — 사이드바 F · 화면 A 또는 G
